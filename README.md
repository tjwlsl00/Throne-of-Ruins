タイトル：廃虚の王座<br>
開発期間：25年06月02日　～　25年07月31日(240時間)<br>
制作人数：1人
--
平和だった王国はある日、モンスターたちによって攻撃を受けることになり、あまりにも強大なモンスターたちの力によって王国は結局廃墟になってしまいます。
廃墟となった王国の王は、王国を再建するために主人公にモンスター チャーチを依頼することになります。
依頼を受けて状況把握のために王国に向かった主人公は、思ったより深刻な状況に大きな衝撃を受けることになります。 「果たして主人公は王国を再建させることができるでしょうか？」 王国の再建のために必死に努力する主人公を描いた物語。

モンスター説明 
--
<ダンジョンモンスター><br>
ウィザード & ゴブリン: プレーヤーを追跡し、攻撃します。 一定時間が経過するとレスポンスされ、 
プレイヤーは反復的な狩りによって成長することができます。 

<ボスモンスター><br>
悪魔の魔法使い: 最終ボスには合計3つのフェーズが存在します。 各フェーズのパターンを避けながらボスを攻撃することが重要です。<br>
1フェーズ(体力100%~70%) - 基本的なダンジョンモンスターと同じように一定距離をパトロールし、攻撃範囲に入るとプレイを攻撃します。<br> 
2フェーズ（体力70%~40%） - 一定周期ごとに空からメテオが落ちます。 <br>
3フェーズ(体力40%~0%) - 1、2フェーズのパターンを維持しながらモンスターを召喚します。 空から落ちてくるメテオを避け、ボスへの進入を妨害するモンスターから抜け出してボスを攻略しなければなりません。


ゲームの流れ
--
プレイヤーは基本的にダンジョン探索によって成長させることができます。ダンジョンで倒したモンスターからの財貨アイテムを使って村NPCから装備やその他の消耗品を購入でき、一定の経験値以上を獲得すると、レベルアップを通じてプレイヤーのスタットポイントを上げることができます。 最終ボス（悪魔の魔法使い）を倒して村を救うまであきらめずに挑戦することがプレイの楽しみのポイントです。
